# Project - Interactive Data Sonification System 

This project involves developing an interactive data sonification system using Pure Data (PD) and Processing. The system takes data from a CSV file (containing weather information) and visualizes it in real time through graphs in Processing. This data is then used to generate real-time sounds, utilizing parameters such as temperature, humidity, wind speed, and precipitation, which affect the generated sounds.

## Objective: 
To create an interactive interface where weather data can modify both the visualization and the sound, providing an immersive experience that combines graphics and audio.

## Implementation
Software Used:

Processing: For data visualization and interaction with controls.

Pure Data (PD): For sonifying the data, generating sounds in real time.

OSC: Protocol used for communication between Processing and Pure Data.
